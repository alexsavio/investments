# CSV Output Contract: Germany Tax Statement

**Version**: 1.0
**Format**: CSV (Comma-Separated Values)
**Encoding**: UTF-8
**Date**: 2026-01-24

## Overview

This document specifies the CSV output format for German tax statements generated by the `investments tax-statement` command with Germany jurisdiction.

## File Structure

- **Header Row**: Column names (required)
- **Transaction Rows**: One row per capital gain, dividend, interest, FX, fee, grant, or corporate action, each in the full 21-column shape
- **Summary Section**: A separate block after a blank line. It has its own 3-column header (`summary_key,label,value_eur`) and holds the aggregate totals, the Anlage KAP / KAP-INV line values, and warnings — it does **not** use the 21-column transaction shape
- **Delimiter**: Comma (`,`)
- **Quote Character**: Double quote (`"`) for fields containing commas or newlines (all free-text `notes` are escaped this way)
- **Empty cells**: inapplicable columns are left empty, never filled with a literal `N/A`
- **Line Terminator**: LF (`\n`) or CRLF (`\r\n`)

## Column Specification

### Transaction Columns

| Column Name | Type | Description | Example | Required |
|-------------|------|-------------|---------|----------|
| `transaction_type` | String | Type of transaction | `"Capital Gain"`, `"Dividend"`, `"Interest"` | Yes |
| `transaction_date` | Date | Trade conclusion date (ISO 8601) | `"2025-03-15"` | Yes |
| `settle_date` | Date | Settlement date (ISO 8601) | `"2025-03-17"` | Yes |
| `symbol` | String | Ticker symbol | `"AAPL"`, `"VWCE.DE"` | Yes |
| `isin` | String | ISIN code | `"US0378331005"` | Yes |
| `description` | String | Human-readable description | `"Sold 100 AAPL"` | Yes |
| `quantity` | Decimal | Shares/units (2 decimals); empty for dividends (records carry no share count) | `"100.00"` | Capital gains / grants |
| `cost_basis_eur` | Decimal | Purchase cost in EUR (2 decimals) | `"9,550.00"` | Capital Gains only |
| `proceeds_eur` | Decimal | Sale proceeds in EUR (2 decimals) | `"14,800.00"` | Capital Gains only |
| `gross_amount_eur` | Decimal | Gross dividend/interest (2 decimals) | `"1,000.00"` | Dividends/Interest only |
| `gross_gain_loss_eur` | Decimal | Before exemptions (2 decimals) | `"5,250.00"` | Capital Gains only |
| `teilfreistellung_pct` | Decimal | Exemption percentage (0-100) | `"30.00"`, `"15.00"`, `"0.00"` | Yes |
| `taxable_amount_eur` | Decimal | After exemptions (2 decimals) | `"3,675.00"` | Yes |
| `foreign_tax_eur` | Decimal | Foreign withholding tax (2 decimals) | `"150.00"` | Yes |
| `abgeltungssteuer_eur` | Decimal | 25% capital gains tax (2 decimals) | `"918.75"` | Yes |
| `solidaritaetszuschlag_eur` | Decimal | 5.5% solidarity surcharge (2 decimals) | `"50.53"` | Yes |
| `kirchensteuer_eur` | Decimal | Church tax 0-9% (2 decimals) | `"73.50"` | Yes |
| `foreign_tax_credit_eur` | Decimal | Foreign tax credited (2 decimals) | `"150.00"` | Yes |
| `total_tax_eur` | Decimal | Sum of German taxes (2 decimals) | `"1,042.78"` | Yes |
| `net_tax_eur` | Decimal | After foreign credit (2 decimals) | `"892.78"` | Yes |
| `notes` | String | Additional notes/warnings | `"Altbestand - tax exempt"`, `"Lenient ECB rate used"` | Optional |

The transaction rows keep the full 21-column shape; inapplicable numeric cells are empty (never `N/A`) and the dividend `quantity` cell is empty. The summary/KAP section follows a blank line and uses its own `summary_key,label,value_eur` header.

## Validation Rules

**Header Row**:

- Must be first row
- Column names must match specification exactly
- Order must match specification

**Transaction Rows**:

- All required columns must be present
- Decimal amounts: exactly 2 decimal places, rounded half away from zero (not truncated)
- Dates: ISO 8601 format (YYYY-MM-DD)
- Empty cells for inapplicable columns (e.g., cost_basis_eur for dividends); never the literal `N/A`

**Summary Rows**:

- Must appear after all transaction rows
- Must include all summary fields
- Amounts must match sum of transaction rows

**Numeric Formatting**:

- Decimal separator: `.` (period)
- Thousands separator: `,` (comma) - optional but recommended for readability
- Negative amounts: `-` prefix (for losses)
- Currency symbol: Not included (all amounts in EUR)

## Error Handling

**Invalid Data**:

- Missing required fields: Omit row, log error
- Invalid dates: Emit warning, use transaction date as fallback
- Negative quantities: Error, halt processing
- Missing ISIN: Use symbol as placeholder, emit warning

**Calculation Errors**:

- Rounding differences: Adjust final summary row to match
- Foreign tax > German tax: Credit only up to German tax amount
- FIFO mismatch: Error, halt processing

## Compatibility

**Import Tools**:

- Excel/LibreOffice Calc: Compatible
- Google Sheets: Compatible
- German tax software: Manual entry required (CSV import not standard)
- Python pandas: `pd.read_csv(file, thousands=',', decimal='.')`

## Versioning

- **Version 1.0**: Initial implementation (2026-01-24)
- Future versions: Add `version` field to header row if format changes
